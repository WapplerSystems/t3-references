T3Bootstrap laedt die Bootstrap-Bausteine erst auf Anforderung. Die Filterleiste benutzt `.form-select`, auf einer Referenzseite steht aber sonst kein Formular - ohne diese Zeile kommen die Regeln nie an, und die Auswahlfelder erscheinen als nackte Browserfelder: eckig, ohne Pfeil, 27 statt 38 Pixel hoch. Faellt lokal nicht auf, wenn das Sitepaket die Formularregeln schon in der Grundausstattung mitbringt. Die Filterleiste steht ausserhalb des nachgeladenen Bereichs: bei einer Auswahl tauscht das Skript nur die Ergebnisse darunter aus, damit der Fokus im gerade bedienten Auswahlfeld bleibt.
Ohne JavaScript bleibt dieser Knopf der Weg zum Filtern. Mit JavaScript blendet ihn das Skript aus, weil die Auswahl selbst schon nachlaedt.
